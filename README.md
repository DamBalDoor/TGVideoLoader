# TGLoader

Telegram-бот для скачивания видео и аудио по ссылке. Отправляешь URL — бот показывает превью, доступные качества с размером файла, после выбора скачивает и присылает результат прямо в чат.

Стек: **Node.js 20+**, [grammy](https://grammy.dev/), [yt-dlp](https://github.com/yt-dlp/yt-dlp) (через `youtube-dl-exec`), [ffmpeg](https://ffmpeg.org/) (через `ffmpeg-static`), [pino](https://getpino.io/) для логов, **SQLite** для аналитики.

## Возможности

- Скачивание **видео** с выбором разрешения, кодека и размера
- Скачивание **только аудио** (M4A/AAC)
- Превью (обложка) и длительность перед скачиванием
- **Обычный** и **расширенный** режим выбора качества (`/settings`)
- Автоматическая конвертация в MP4 и сжатие, если файл больше лимита Telegram
- Разбор VK-ссылок с внешними embed (Coub, YouTube и др.)
- Закрытый режим — доступ только для указанных пользователей
- Встроенная **аналитика**: уникальные пользователи и скачивания за день / месяц / год
- Ежедневный отчёт владельцу в ЛС (только при изменении цифр)
- Один процесс — защита от двойного запуска (`.bot.lock`)

## Как это работает

```
Пользователь → ссылка в чат
      ↓
Бот читает форматы через yt-dlp
      ↓
Сообщение с превью + inline-кнопки качества (и «Аудио»)
      ↓
Пользователь выбирает вариант
      ↓
Скачивание → remux в MP4 / конвертация аудио → сжатие при необходимости
      ↓
Отправка video / audio / document в Telegram
```

1. Пользователь отправляет текст со ссылкой (или ссылку в подписи).
2. Бот вызывает `listFormats`, показывает превью и клавиатуру с вариантами.
3. После нажатия кнопки клавиатура убирается, статус обновляется в caption.
4. Файл скачивается во временную папку `downloads/`, обрабатывается ffmpeg и отправляется.
5. Временные файлы удаляются. Сессия выбора качества живёт до 30 минут.

## Быстрый старт

### 1. Клонировать и установить зависимости

```bash
git clone https://github.com/DamBalDoor/TGVideoLoader.git
cd TGVideoLoader
npm install
```

### 2. Настроить окружение

```bash
cp .env.example .env
```

Открой `.env` и укажи как минимум:

```env
BOT_TOKEN=123456789:ABCdef...
```

### 3. Запустить

```bash
npm start
```

### 4. Проверить

Напиши боту `/start` и отправь ссылку на видео.

## Конфигурация

Все параметры задаются в файле `.env` в корне проекта.

| Переменная | Обязательно | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | да | — | Токен от @BotFather |
| `ALLOWED_USER_IDS` | нет | пусто | Telegram user id через запятую. Пусто = бот открыт для всех |
| `ADMIN_USER_ID` | нет* | — | id владельца: ежедневный отчёт и команда `/analytics` |
| `REPORT_HOUR` | нет | `5` | Час отправки отчёта (0–23) |
| `REPORT_MINUTE` | нет | `0` | Минута отправки отчёта (0–59) |
| `REPORT_TIMEZONE` | нет | `Asia/Bangkok` | Часовой пояс для аналитики и расписания ([список IANA](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones)) |
| `ANALYTICS_DB_PATH` | нет | `data/analytics.db` | Путь к SQLite-базе аналитики |
| `COOKIES_FILE` | нет | — | Путь к `cookies.txt` (формат Netscape) |
| `COOKIES_FROM_BROWSER` | нет | — | Загрузить cookies из браузера: `chrome`, `edge`, `firefox` |
| `MAX_HEIGHT` | нет | `720` | Максимальная высота по умолчанию, если формат не выбран |
| `YTDLP_AUTO_UPDATE` | нет | `1` | Автообновление yt-dlp при старте. `0` = выключить |
| `YTDLP_UPDATE_INTERVAL_HOURS` | нет | `24` | Не проверять обновления чаще этого интервала |
| `YTDLP_UPDATE_TIMEOUT_SEC` | нет | `120` | Таймаут обновления yt-dlp в секундах |
| `LOG_LEVEL` | нет | `info` | Уровень логов: `fatal`, `error`, `warn`, `info`, `debug`, `trace` |
| `LOG_PRETTY` | нет | авто | `1` — читаемый вывод в терминале, `0` — JSON |

\* Нужен для аналитики и ежедневных отчётов. Свой id можно узнать у [@userinfobot](https://t.me/userinfobot).

### Пример `.env` для личного бота

```env
BOT_TOKEN=123456789:ABCdef...
ADMIN_USER_ID=987654321
REPORT_TIMEZONE=Europe/Moscow
REPORT_HOUR=5
REPORT_MINUTE=0
LOG_LEVEL=info
```

### Закрытый бот (только для своих)

```env
ALLOWED_USER_IDS=111111111,222222222
```

## Команды бота

| Команда | Кому доступна | Описание |
|---|---|---|
| `/start` | всем | Приветствие и краткая справка |
| `/help` | всем | То же, что `/start` |
| `/settings` | всем | Обычный / расширенный режим выбора качества |
| `/analytics` | только `ADMIN_USER_ID` | Расширенная сводка за **сегодня** |
| `/analytics week` | только `ADMIN_USER_ID` | Сводка за **7 дней** с таблицей |
| `/analitics` | только `ADMIN_USER_ID` | Алиас `/analytics` |

Для обычных пользователей команды аналитики **не существует** — бот молчит, не выдавая ошибку.

Скачивание запускается **отправкой ссылки** — отдельной команды нет.

## Режимы выбора качества

### Обычный (по умолчанию)

- Одна кнопка на каждое разрешение (1080p, 720p, …)
- Предпочтение H.264 / MP4
- Внизу — кнопка **«Аудио»**

### Расширенный (`/settings` → включить)

- Полный список: ширина × высота, FPS, кодек, размер
- До 5 вариантов аудио с разным битрейтом
- Полезно, если нужен VP9, AV1, HEVC и т.д.

Настройка хранится в SQLite (`data/analytics.db`) и сохраняется после перезапуска бота.

## Аналитика

Бот автоматически считает:

- **Уникальных пользователей** — один визит в сутки на пользователя (любое сообщение или нажатие кнопки)
- **Скачивания** — успешная отправка видео или аудио

Данные хранятся локально в SQLite (`data/analytics.db`, движок [sql.js](https://sql.js.org/)).

### Ежедневный отчёт

Каждый день в **05:00** по `REPORT_TIMEZONE` бот присылает в ЛС `ADMIN_USER_ID` отчёт **за вчера**:

```
📊 Отчёт TGLoader за 7 сентября 2026

Уникальные пользователи:
• За сутки: 5
• За месяц: 23
• За год: 156

Скачивания:
• За сутки: 3 (видео: 2, аудио: 1)
• За месяц: 18
• За год: 94
```

Отчёт **не отправляется**, если:

- цифры не изменились с прошлого уведомления;
- в базе ещё нет данных.

### Ручная сводка

Админ может запросить расширенную аналитику:

- `/analytics` — за **сегодня**: пользователи, скачивания (видео/аудио), топ площадок, накопительно за месяц и год
- `/analytics week` — за **последние 7 дней** с таблицей по дням

Отчёт отправляется как **Rich Message** (статья Telegram) с нативной таблицей. Если клиент не поддерживает новый формат, бот пришлёт HTML-fallback с `<pre>`-таблицей.

## Автообновление yt-dlp

При каждом старте бот проверяет обновления yt-dlp, но **не чаще одного раза в 24 часа** (настраивается). Это снижает поломки после изменений на YouTube, TikTok и других площадках.

Состояние последней проверки хранится в `data/ytdlp-last-update.json`. В логах видно, была ли установлена новая версия.

```env
YTDLP_AUTO_UPDATE=1
YTDLP_UPDATE_INTERVAL_HOURS=24
YTDLP_UPDATE_TIMEOUT_SEC=120
```

Отключить: `YTDLP_AUTO_UPDATE=0`

## Логирование

Логи пишет [pino](https://getpino.io/) с дочерними логгерами по модулям (`bot`, `download`, `analytics`, `vk`, `ffmpeg` и др.).

| Режим | Когда |
|---|---|
| Pretty (цветной текст) | Локальная разработка, терминал |
| JSON | Production, PM2, сбор логов |

```env
LOG_LEVEL=info    # для отладки: debug
LOG_PRETTY=0      # принудительно JSON
```

При запуске через PM2 JSON включается автоматически (`ecosystem.config.cjs`).

## Cookies для Instagram / TikTok / YouTube

Некоторые площадки требуют авторизацию. Если бот отвечает ошибкой или не видит видео:

**Вариант 1 — файл cookies**

1. Экспортируй `cookies.txt` из браузера (расширение «Get cookies.txt LOCALLY» или аналог).
2. Укажи путь в `.env`:

```env
COOKIES_FILE=C:\path\to\cookies.txt
```

**Вариант 2 — cookies из браузера**

```env
COOKIES_FROM_BROWSER=chrome
```

Поддерживаются `chrome`, `edge`, `firefox`. Браузер должен быть установлен на той же машине, где работает бот.

## Запуск в production (PM2)

Конфиг: [`ecosystem.config.cjs`](ecosystem.config.cjs)

```bash
npm install -g pm2
npm run pm2:start     # запуск
npm run pm2:logs      # просмотр логов
npm run pm2:restart   # перезапуск
npm run pm2:stop      # остановка
```

| Параметр | Значение |
|---|---|
| Имя процесса | `tgloader` |
| Инстансы | **1** (второй экземпляр вызовет конфликт polling) |
| Логи PM2 | `logs/pm2-out.log`, `logs/pm2-error.log` |
| Автоперезапуск | да |
| Лимит памяти | 512 МБ |

Автозапуск PM2 после перезагрузки сервера:

```bash
pm2 startup
pm2 save
```

## Ограничения

| Ограничение | Детали |
|---|---|
| **50 МБ** | Лимит Telegram Bot API на один файл. Варианты больше 49 МБ помечаются; бот пробует сжать |
| **Один процесс** | Нельзя запускать два экземпляра с одним токеном — будет ошибка 409 Conflict |
| **Cookies** | Instagram, TikTok, X, Pinterest часто требуют cookies |
| **Приватный контент** | Бот скачивает только то, что доступно по публичной ссылке без логина |

Для файлов **больше 50 МБ** потребуется локальный [Telegram Bot API Server](https://core.telegram.org/bots/api#using-a-local-bot-api-server) — в текущей версии не реализовано.
